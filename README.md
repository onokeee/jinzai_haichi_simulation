# NAND工場 メンテナンス担当 最適配置シミュレータ

過去の実績データから「メンテナンス担当の人数」と「不良・装置停止」の関係を学習し、
工場全体の生産数が最大になる人員配置を計算する Streamlit アプリです。
高校生インターンシップで、DX の「D（デジタル・データ活用）」を紹介するデモ用に作成しました。

※ 同梱のサンプルデータはすべて架空です。

## できること

- **シミュレーション**：ライン数と、スキル別（新人・中堅・ベテラン）のメンテナンス担当の人数を入れると、
  生産数が最大になる人員配置と、生産数・不良数・停止で作れなかった数を表示します。
- **パターン比較**：条件の違う複数のパターン（増員・育成・退職など）を並べて、生産数と人員配置を比べます。

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 実績データ（CSV）

サイドバーからアップロードできます（UTF-8 / Shift-JIS）。ひな形はアプリの「CSVひな形をダウンロード」から取得できます。

| 列 | 内容 |
|---|---|
| 年月 | 例：2025-04 |
| 世代 | ライン（製品の世代）の名前 |
| 装置台数 | そのラインの装置台数 |
| 新人 / 中堅 / ベテラン | その月の担当人数（スキル別） |
| 投入数 | その月に投入したウエハの枚数 |
| 稼働率(%) | 装置の稼働率 |
| 不良数 | 不良で廃棄になったウエハの枚数 |

## 計算のしくみ

- スキルを考えたメンテの量（新人 0.6・中堅 1.0・ベテラン 1.4 人ぶんとして換算）を装置台数で割り、
  「装置1台あたりのメンテの量」と不良率・稼働率の関係を、ラインごとに指数関数で当てはめます（最小二乗法）。
- 生産数 ＝ 投入数 − 停止で作れなかった数 − 不良数
- 人員配置は動的計画法で求めています。すべての配置を調べたのと同じ、生産数が最大になる配置が得られます（各ラインに最低1人）。
