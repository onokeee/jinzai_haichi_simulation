# メンテナンス担当 最適配置シミュレータ

NANDフラッシュメモリ工場（製品の世代ごとに3つのライン）を題材に、
過去の実績データから「メンテナンス担当の人数」と「不良・装置停止」の関係を学習し、
生産数（または金額）が最大になる人員配置を計算する Streamlit アプリです。
高校生インターンシップで、DX の「D（デジタル・データ活用）」を紹介するデモ用に作成しました。

※ 実績データはアプリ内で作る架空のサンプルです（3ライン × 24か月）。

## できること

- **最適配置**：スキル別（新人・中堅・ベテラン）のメンテナンス担当の人数を入れると、
  生産数（または金額）が最大になる人員配置と、生産数・不良数・停止で作れなかった数を表示します。
- **人数と生産数の関係**：設定中の総人数を新人・中堅・ベテランに分ける全通り（15人なら136通り）について、
  同じ比率のまま人数を増やしたときの生産数（または金額）を折れ線で表示します。
  人数を増やすと伸びが小さくなり、頭打ちになる様子がひと目でわかります。
- **もとにした実績データ**：担当人数と生産数の実績と、そこから学習した傾向を表示します。

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 計算のしくみ

- スキルを考えたメンテの量（新人 0.6・中堅 1.0・ベテラン 1.4 人ぶんとして換算）を装置台数で割り、
  「装置1台あたりのメンテの量」と不良率・稼働率の関係を、ラインごとに指数関数で当てはめます（最小二乗法）。
- 生産数 ＝ 投入数 − 停止で作れなかった数 − 不良数、金額 ＝ 生産数 × ウエハ1枚の単価
- 人員配置は動的計画法で求めています。すべての配置を調べたのと同じ、一番よい配置が得られます（各ラインに最低1人）。
